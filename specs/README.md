# AI Workflow Engine

All planning documents for this project.

## Structure

```
specs/
├── state.yaml                  # Session state, active flow, handoff
├── release-plan.yaml           # Release index, WSJF epic list
├── execution-status.yaml       # Story/epic progress
├── planning-status.yaml        # Discover-phase checklist
├── product/                    # Vision, scope, glossary
│   └── snapshots/              # Frozen release baselines
├── tech-architecture/          # Stack, security, test, design docs
├── adr/                        # Architecture Decision Records
├── epics/                      # Epic definitions and stories
│   └── archive/                # Completed/abandoned epics
├── verifications/              # Verification artifacts
└── bugs/                       # Bug reports and registry
```
